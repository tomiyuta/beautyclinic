### 1. データベースマイグレーション実行

```bash
# Prismaクライアント再生成
npx prisma generate

# マイグレーション実行
npx prisma migrate dev --name add_content_generation_extensions

# または、本番環境の場合
npx prisma migrate deploy
```

**注意事項:**
- MySQL 8.0.19未満の場合は`IF NOT EXISTS`がサポートされていない可能性があります
- マイグレーションファイルは `prisma/migrations/20251122100732_add_content_generation_extensions/migration.sql` に準備済み

## 環境変数設定

以下の環境変数が必要です：

```env
# OpenAI API（テキスト・画像生成用）
OPENAI_API_KEY=sk-...

# Pika Labs API（短尺動画生成用 - フェーズ2）
PIKA_LABS_API_KEY=...

# Synthesia API（説明動画生成用 - フェーズ2）
SYNTHESIA_API_KEY=...

# データベース
DATABASE_URL=mysql://...
```

## 技術的注意事項

1. **Pika Labs API**: 実際のAPI仕様が不明確なため、要調査
2. **Synthesia API**: 実際のAPI仕様が不明確なため、要調査
3. **ファイルストレージ**: 動画ファイルは大きいため、外部ストレージ必須
4. **MySQLバージョン**: 8.0.19未満の場合はマイグレーションSQLを手動調整が必要な可能性
