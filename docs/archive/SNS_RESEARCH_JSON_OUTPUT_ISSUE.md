# SNS調査結果がJSON形式で出力される問題の原因分析

## 問題の概要

Instagram、YouTube、TikTokの調査結果がJSON形式で出力されている。

## 原因分析

### 1. TikTokのプロンプト（意図的なJSON出力）

TikTokのプロンプトは、新しい構造化形式に変更されており、`<CONSENSUS_JSON>`と`<REPORT_MARKDOWN>`の2部構成を要求している。これは**意図的な設計**であり、JSON出力は正常な動作。

**プロンプトの指示:**
```
出力は「2部構成・日本語・順番厳守」。次のタグで区切って返してください：

1) <CONSENSUS_JSON> … AI合議・採点用の"隠しJSON"（機械処理用）。UIには表示しない。
2) <REPORT_MARKDOWN> … 人が読む研究レポート（Markdown）。運用Tipsや投稿助言は含めない。
```

### 2. InstagramとYouTubeのプロンプト（JSON出力が意図されていない）

InstagramとYouTubeのプロンプトは、**通常のテキスト形式**を要求しているが、Gemini APIが自動的にJSON形式で返答している可能性がある。

**現在のプロンプトの指示:**
```
わかりやすく読みやすい形式で、調査結果をまとめてください。最後に、トレンド分析の総括を記載してください。
```

**問題点:**
- 「わかりやすく読みやすい形式」という指示が曖昧
- Gemini API（特にGemini 2.0以降）は、構造化された出力を好む傾向がある
- プロンプトに「JSON形式ではなく、Markdown形式で出力」という明示的な指示がない

## 根本原因

1. **Gemini APIの動作特性**: Gemini 2.0以降のモデルは、構造化されたデータを出力する傾向がある
2. **プロンプトの曖昧さ**: 「わかりやすく読みやすい形式」という指示が、GeminiによってJSON形式と解釈されている可能性
3. **明示的な出力形式の指定がない**: InstagramとYouTubeのプロンプトに、出力形式（Markdown/テキスト）の明示的な指示がない

## 解決策

### オプション1: InstagramとYouTubeのプロンプトを修正（推奨）

プロンプトに明示的に「Markdown形式で出力」「JSON形式ではなく、読みやすいテキスト形式で出力」という指示を追加する。

**修正例:**
```
【出力形式】
- JSON形式ではなく、Markdown形式で出力してください
- 見出し、箇条書き、表などを使用して、読みやすい形式でまとめてください
- コードブロックやJSON形式は使用しないでください

わかりやすく読みやすいMarkdown形式で、調査結果をまとめてください。最後に、トレンド分析の総括を記載してください。
```

### オプション2: TikTokと同様の構造化形式に統一

InstagramとYouTubeも、TikTokと同様に`<CONSENSUS_JSON>`と`<REPORT_MARKDOWN>`の2部構成に変更する。

**メリット:**
- 一貫性のある出力形式
- 構造化データの活用が可能
- 機械処理と人間向けレポートの分離

**デメリット:**
- プロンプトの複雑化
- 出力処理の変更が必要

### オプション3: 応答処理でJSONを除去

`callGemini`関数の応答処理で、JSON部分を自動的に除去し、Markdown部分のみを返す。

**問題点:**
- JSONとMarkdownの区別が困難
- TikTokの`<CONSENSUS_JSON>`も除去されてしまう可能性

## 推奨される対応

**オプション1を推奨**: InstagramとYouTubeのプロンプトに、明示的に「Markdown形式で出力」「JSON形式は使用しない」という指示を追加する。

これにより：
- プロンプトの意図が明確になる
- Gemini APIがJSON形式で返答する可能性が低くなる
- 既存のコード変更が最小限で済む

## 実装の優先順位

1. **高**: InstagramとYouTubeのプロンプト修正（オプション1）
2. **中**: TikTokの`<CONSENSUS_JSON>`をUIで非表示にする処理（既存の設計通り）
3. **低**: 応答処理での自動JSON除去（オプション3、ただしTikTokには適用しない）
