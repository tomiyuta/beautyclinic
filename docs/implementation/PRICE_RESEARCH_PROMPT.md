# 価格調査プロンプト

## 概要

価格調査（`researchPriceComparison`）で使用されるプロンプトの詳細です。

## プロンプトテンプレート

### 基本テンプレート（`prompt-helper.ts`）

```
あなたは美容皮膚科クリニックの価格調査専門家です。
以下の都市の美容クリニックでの施術価格を調査してください：

都市: ${cities}
施術: ${treatments}

各都市・各施術について、以下の情報を含めてわかりやすくまとめてください：

- 都市名
- 施術名
- 平均価格（数値）
- 価格帯の説明
- 調査件数（推定）

最後に、価格比較の総括を記載してください。
```

### 実際に使用されるプロンプト（`gemini.ts`）

実際の実行時には、以下のプロンプトが使用されます：

【重要】以下のWeb検索結果を基に、最新の価格情報を分析してください。

## Web検索クエリ

価格調査では、以下のクエリでWeb検索を実行します：

```
generatePriceSearchQuery(treatments, cities, currentYear, currentMonth)
```

**例**:
```
"東京都 大阪府 美容クリニック ボトックス ヒアルロン酸 価格 2025年11月"
```

## プロンプトの処理フロー

1. **基本テンプレートの取得**: `prompt-helper.ts`から`gemini_research_price_comparison`テンプレートを取得
2. **Web検索の実行**: `generatePriceSearchQuery`でクエリを生成し、Web検索を実行
3. **プロンプトの構築**: 
   - 基本テンプレートにWeb検索結果を追加
   - プレースホルダー（`${cities}`, `${treatments}`, `${currentDate}`など）を置換
4. **AI API呼び出し**: 構築されたプロンプトをGemini APIに送信

## 実装ファイル

- **プロンプトテンプレート**: `src/server/services/prompt-helper.ts` (168行目)
- **実装関数**: `src/server/services/gemini.ts` (736行目)
- **Web検索クエリ生成**: `src/server/services/web-search.ts` (149行目)

## 出力形式の期待

AIは以下の形式で結果を返すことが期待されます：

```
【価格調査結果】

[YYYY年MM月]時点のWeb情報に基づき実施

## [都市名1] - [施術名1]
- 平均価格: [数値]円
- 価格帯: [説明]
- 調査件数: [推定件数]
- 情報源: [URL]

## [都市名1] - [施術名2]
...

## [都市名2] - [施術名1]
...

## 価格比較の総括
[総括テキスト]
```

## 注意事項

1. **最新情報の優先**: Web検索結果の最新情報を優先的に使用
2. **古い情報の除外**: 2024年以前の情報は使用しない
3. **出典の明記**: 情報の出典（URL）を可能な限り明記
4. **日付の記載**: 調査結果のタイトルや冒頭に実施日時を記載
